# 大田区総合体育館（12/12・12/13）座席数

## 日付・slug について

- **大会は 2026 年 12 月**（12/12 準決勝・12/13 決勝）。
- リポジトリの slug `2025-12-12` / `2025-12-13` は **PDF・PNG ファイル名から付けた内部キー**です（`scripts/pdf_slug.py`）。表示は UI の「12/12」「12/13」タブ。年を slug に含める場合はアセット一式のリネームが必要です。

## 数え方（拡大 PDF は使わない）

拡大 PDF は部品の重なき・非表示図形のため **席数のソースにしない**。

正本: [`data/ota-seat-definition.json`](../data/ota-seat-definition.json)

- ブロック幅・7 段・Q の 1–4 / 14–17 非販売・通路 5–13（席なし）をデータで保持
- 2階は `free2F: 1952` のみ（JSON ルートの `floor2_free_capacity`）

### コマンド

```bash
python scripts/generate_ota_seats.py
python scripts/ota_inventory_report.py 2025-12-13
```

地図上の **x,y,w,h** だけ、重なき除去した拡大 PDF 矩形を **順序マッチ**で付ける（カウントには使わない）。

## 3D（ota-seat-view.html）と座席表の差

- **Q**: 1–4・14–17 番は灰色非販売（56 席）。5–13 は通路で席レコードなし。
- **S ブロック**: **座席表どおり 13 席×7 段すべてチーム券（緑）**。3D で S の 9 番以降が灰に見える場合は不具合扱い（`otaTeamGray` は Q のみ）。
