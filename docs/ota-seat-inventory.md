## PDF 抽出との差

`npm run extract-seats`（`scripts/extract_seats_from_pdf.py`）は拡大PDF内の **~13.6pt 塗り矩形**を1席として数えます。現状おおよそ **2,505** 矩形（1階＋2階の一部）で、**1,533＋1,952 とは一致しません**。コートサイド等は別サイズ矩形のため別途取り込みが必要です。

照合:

```bash
python scripts/extract_seats_from_pdf.py
python scripts/ota_inventory_report.py 2025-12-13
```
