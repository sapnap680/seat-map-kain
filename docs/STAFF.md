# スタッフ向け操作ガイド

## ログイン

1. サイト右上の **スタッフログイン**
2. 共有のメールアドレスとパスワードを入力（Supabase で発行したアカウント）
3. 画面上部に「編集中」と表示されれば OK

（ローカルデモのみ: パスワード `staff-demo`）

## 最終2日（12/12・12/13）の男子/女子

- **コートサイド・エンド・スペシャル席**は、画面上部の **男子側を表示 / 女子側を表示** で在庫が切り替わります（同じ座席でも男子用と女子用の販売状況を別々に管理）。
- **1階席**は **終日共通** です。男子/女子の切替をしても 1 階の表示・在庫は変わりません（水色の枠線）。
## 前売り・当日の記録

1. 該当する **試合日タブ** を選択
2. （最終2日なら）案内する試合に合わせて **男子/女子** を選択
3. 売れた席をタップ
4. **前売り済** または **当日販売済** を選ぶ
5. 必要ならメモ（例: 「ペア購入」「通路側希望」）を入力して **保存**

保存後、他のスタッフの画面も数秒以内に更新されます（ページを開き直す必要はありません）。

## 当日の空席案内

1. **空席のみハイライト（案内用）** にチェック
2. **緑色** の席だけがはっきり見えます（売れ席は薄く表示）
3. 来場者には緑の席を案内

## トラブル

- **保存できない**: ログインし直す。Supabase のネットワークを確認
- **図が表示されない**: `public/backgrounds/` に PNG があるか、または `events.background_path` が正しいか確認
- **更新が反映されない**: Realtime が有効か SQL マイグレーションを再確認
